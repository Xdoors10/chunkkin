# Chunkkin

Высокопроизводительный оригинальный плагин предварительной генерации мира (world pre-generator) для серверного ядра **Pumpkin** на языке **Rust** в архитектуре WebAssembly Component Model (WASI).

---

## ⚡ Особенности

- **Спиральный алгоритм обхода (Spiral Engine):** генерация чанков начинается от центра (точки спавна или заданных координат) и распространяется наружу концентрическими слоями.
- **Геометрические маски:**
  - `square` — квадратная область;
  - `circle` — круглая (радиальная) область с точным расчетом евклидова расстояния.
- **Асинхронная пакетизация (Batching):** регулируемый размер батча генерации за тик сервера, предотвращающий просадки TPS и лаги основного игрового цикла.
- **Управление задачами (Pause & Resume):** возможность приостанавливать генерацию, сохранять текущую позицию спирали на диск и возобновлять процесс после перезагрузки или планового рестарта сервера.
- **Детальная телеметрия и прогресс:**
  - Визуальный прогресс-бар в чате и консоли;
  - Точный подсчет скорости генерации (чанков в секунду);
  - Расчетное время завершения (ETA) и прошедшее время;
  - Автоматическое сохранение мира на диск через настраиваемые интервалы.
- **Интеграция с Pumpkin API:**
  - Полная поддержка дерева команд Brigadier с автодополнением (tab-completion) аргументов для миров и форм;
  - Изоляция памяти внутри песочницы WebAssembly (Wasmtime).

## 📋 Команды и права

Основная команда: `/chunkkin` (алиасы: `/pregen`, `/ck`).
Требуемое право доступа: `pumpkin.command.chunkkin` (по умолчанию доступно операторам сервера).

| Команда | Описание | Пример |
|---|---|---|
| `/chunkkin start [мир] [радиус] [форма]` | Запуск новой задачи предварительной генерации | `/chunkkin start world 1000 square` |
| `/chunkkin pause` | Приостановка текущей задачи с фиксацией прогресса | `/chunkkin pause` |
| `/chunkkin continue` / `/chunkkin resume` | Возобновление приостановленной задачи | `/chunkkin continue` |
| `/chunkkin cancel` / `/chunkkin stop` | Полная отмена текущей задачи и сброс состояния | `/chunkkin cancel` |
| `/chunkkin status` / `/chunkkin progress` | Отображение детального отчета о ходе генерации | `/chunkkin status` |
| `/chunkkin trim [мир] [радиус]` | Проверка границ и расчет чанков за пределами радиуса | `/chunkkin trim world 1000` |
| `/chunkkin help` | Справка по всем доступным командам | `/chunkkin help` |

> [!TIP]
> Параметры в `/chunkkin start` опциональны: если не указаны, берутся значения по умолчанию из конфигурации (`world`, `500` блоков, `square`).

## ⚙️ Конфигурация (`config.json`)

При первом запуске плагин создает конфигурационный файл в своей изолированной директории данных `plugins/data/chunkkin/config.json`:

```json
{
  "default_radius": 500,
  "default_shape": "square",
  "batch_size": 16,
  "log_interval_ticks": 100,
  "auto_save_interval_chunks": 1000,
  "auto_resume_on_startup": true
}
```

### Описание параметров:
- `default_radius` (целое число): радиус генерации по умолчанию в блоках.
- `default_shape` (`"square"` или `"circle"`): форма области по умолчанию.
- `batch_size` (целое число): количество чанков, обрабатываемых за один серверный тик (20 тиков = 1 сек).
- `log_interval_ticks` (целое число): частота вывода информационных сообщений о прогрессе в тиках (100 тиков = 5 секунд).
- `auto_save_interval_chunks` (целое число): через каждые N сгенерированных чанков вызывается сохранение мира на диск.
- `auto_resume_on_startup` (`true`/`false`): автоматически продолжать генерацию при запуске сервера, если она была активна.

## 🛠️ Сборка и установка

### Требования
- Язык Rust версии **1.85+** (Editions 2021/2024).
- Целевая платформа WebAssembly Component Model:
  ```bash
  rustup target add wasm32-wasip2
  ```

### Сборка плагина
Выполните команду сборки релизного бинарника:
```bash
cargo build --target wasm32-wasip2 --release
```

Готовый артефакт WebAssembly будет находиться по пути:
```text
target/wasm32-wasip2/release/chunkkin.wasm
```

### Установка на сервер Pumpkin
1. Скопируйте файл `chunkkin.wasm` в папку `plugins/` вашего сервера Pumpkin.
2. В файле настроек сервера `pumpkin.toml` убедитесь, что плагины включены:
   ```toml
   [plugins]
   enabled = true
   ```
3. Запустите сервер или выполните команду `/reload`.
